# VS Code の Swift 拡張の落とし穴

- Swift パッケージのルートに、`.d` / `.dia` / `.swiftdeps` / `.swiftmodule` などの中間生成物が大量に出たら、拡張の索引用ビルドを疑う。エディタ以外 (コマンドラインの編集など) による変更でも走ることがあり、`swift build` や `swift test` では出ない
- テストを流したせいと決めつけない。拡張の設定で止まらないときは、拡張の無効化で止まるかを確かめる
- これらは中間生成物なので、`git ls-files --others` で管理外であることを確かめてから消す。テスト担当は消さずに、出ていることを報告する
